✨ Baat-Cheet Extra Features
Language • Privacy • Backup • Data Saver

🌐 App Language / भाषा

Language badalne par supported common labels translate honge. Kuch purane/custom text abhi original language mein reh sakte hain.

🔐 Privacy Center

Yeh preferences isi browser/device par save hoti hain. Server-side privacy rules ko Firebase rules mein alag se configure karna hota hai.

💾 Backup & Restore

Local backup is device/browser data ka JSON export hai. Isse Firebase server backup ya dusre device par automatic sync na samjhein.

📶 Data Saver

Data saver preference save hoti hai; actual image/video compression aur Firebase download limits ko app ke media upload/download code mein integrate karna hoga.

🎙️ Voice to Text

Supported browsers mein microphone se message likh sakte hain. Microphone permission zaroori hai.

⭐ Quick tools

Current chat ko favorite mark karne aur local favorite list dekhne ke shortcuts.

ℹ️ Help & reliability

Purane Firebase chat/login/call features ko preserve kiya gaya hai. OTP, live messaging, calls, cloud backup, message translation aur server privacy settings ko Firebase/provider configuration ke saath real device par test karna zaroori hai.
